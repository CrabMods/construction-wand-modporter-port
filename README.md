# Construction Wand - Unofficial ModPorter Port

This repository is an unofficial developer baseline for bringing
[Construction Wand](https://github.com/Theta-Dev/ConstructionWand) from
Minecraft Forge 1.20.1 to NeoForge 1.21.1. It is intended for research,
learning, community review, and reducing the repetitive work required for a
manual port.

The port is generated by [ModPorter](https://github.com/CrabMods/modporter), a
rules-based Forge 1.20.1 to NeoForge 1.21.1 migration tool. The mod logic in
this repository is intended to be produced by reusable transformation rules,
without a separately maintained Construction Wand feature fork. When review
finds a repeatable migration defect, the preferred fix is to improve ModPorter
and regenerate the port.

This project is not an official Construction Wand release and is not
affiliated with or endorsed by ThetaDev. Human review and focused playtesting
are expected before wider distribution.

## Current Status

Release preparation is in progress as of November 9, 2026. The generated
source used for the strict benchmark has passed the source-project checks
below. The public candidate source package and packaged JAR have not yet been
built in this repository, so no binary is currently offered here.

| Verification | Strict source-project result |
| --- | --- |
| Compile against Minecraft 1.21.1 and NeoForge 21.1.230 | Passed |
| Dedicated server start and controlled stop | Passed |
| Client boot and saved-world load | Passed |
| Creative inventory opened; all displayed stacks in the relevant tabs were browsed | Passed |
| Strict log audit with no unexplained porter-related warnings or errors | Passed |
| Source-project GameTest run | Passed, 1/1 required test |

These checks cover project loading and the in-game item interface. Detailed
behavior of individual items and blocks is the next area for developer review
and focused playtesting; it is outside this verification round.

Packaged-candidate validation will be recorded after an exact JAR is built and
tested from a clean `mods` directory rather than from Gradle source sets. See
[PORTING.md](PORTING.md) for provenance, validation boundaries, and the release
checklist.

## Repository and Branches

The repository name is `construction-wand-modporter-port`. The `1.21.1` branch
contains the NeoForge 1.21.1 line. A future Minecraft target should use its own
version branch rather than changing the meaning of this branch.

## Reporting Issues

Please report generated-port and migration problems primarily to the
[ModPorter issue tracker](https://github.com/CrabMods/modporter/issues). Include:

- the ModPorter version and commit;
- the upstream repository and commit;
- the Minecraft and NeoForge versions;
- the exact build or runtime step;
- the relevant log excerpt and, when available, the packaged JAR checksum.

ModPorter handles candidate-specific migration reports. Problems reproduced
in an official Construction Wand release can follow the upstream project's
normal reporting process.
